# History Reimagined

**History Reimagined** is an AI storytelling platform that lets users explore alternate histories with text and images. Enter a scenario like *“What if Cleopatra met Einstein?”*, and the platform generates immersive narratives and visuals from that reimagined world.

## Features

- Generate AI-powered historical narratives
- Generate AI visuals for key scenes and characters
- Intuitive “Reimagine” interface for creative exploration
- Save and revisit your story timelines

---

## Tech Stack

- **Frontend**: React + AWS Amplify  
- **Backend**: AWS Lambda + API Gateway  
- **Database**: DynamoDB (store prompts & story timelines)  
- **AI Models**: Amazon Bedrock (text and image generation)  
- **Storage**: Amazon S3 (story assets)
